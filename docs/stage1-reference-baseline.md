# 第一关复刻 — 原版对照基准（Reference Baseline）

> 本文档裁定复刻的**对照基准**，并列出原版第一关的已知事实。
> 每条事实标注信息来源与确信度，**不把印象当成事实**：
> 未能核实的条目一律进入「待用户对照原版核实」清单，由持有合法原版的用户最终确认。
>
> 配套文档：[`stage1-fidelity-checklist.md`](stage1-fidelity-checklist.md)（逐项复刻状态与差异）。

---

## 1. 版本裁定：NES / FC 版《Contra》（1988）

**基准 = NES（FC）版，而非 1987 年街机版。** 裁定依据：

1. 用户合法取得并提供用于对照的素材是 **NES 剥离图组**：`players.png`（2081×1075，
   含 © KONAMI 1988 标识）、`stage1bg.png`（3456×245）、`tiles1.png`、`wall1.png` 等，
   均为 NES 版像素规格（16px 瓦片网格、NES 调色板）。
2. `stage1bg.png` 经验证**就是 NES 第一关完整关卡布局图**（216 列 × 3456px），
   本项目的关卡数据由它数值化提取（`tools/stage1_extract.py` →
   `src/level/stage1ImageData.ts`），并以 1:1 世界锁定绘制。
3. 历史开发轮次均以该素材为唯一视觉对照。

街机版（1987）与 NES 版在第一关的敌人配置、武器掉落方式、Boss 形态上均有差异；
**本项目不声称对照街机版**。若用户希望改对照街机版，需先提供合法取得的街机版参考。

## 3. 待用户对照原版核实清单（U 系列）

按优先级排列，建议用户对着自己合法持有的 NES 版第一关逐项确认：

| # | 待核实项 | 影响 | 建议核实方式 |
|---|---|---|---|
| U1 | 玩家奔跑速度、跳跃高度/距离、下蹲判定框的精确数值 | 手感保真度 | 同场景对比（如同步起跳过 2 格台阶/3 格沟） |
| U2 | 第一关敌人种类清单与出现顺序（哪些兵种在哪些路段出场） | 敌人刷新编制 | 记录原版一局内敌人出现的位置/顺序，与波次表比对 |
| U3 | 各敌人/Boss/武器/通关的得分值 | 计分复刻 | 对照原版得分显示 |
| U4 | Boss HP（受弹次数）、攻击 pattern、阶段转换点 | Boss 战复刻 | 实测原版 Boss 受弹次数与弹幕 pattern |
| U5 | 桥面破坏方式（是否仅爆炸可破 / 普通子弹是否可破 / 一发破几板） | 地形互动 | 原版实测；本项目现为「普通子弹一发破 1 板 + 爆炸破 1 板」 |
| U6 | BGM 速度与音效触发时点（跳跃/射击/爆炸/死亡/通关） | 音频节奏对齐 | 听感比对；本项目为原创替代，只对结构不对音符 |
| U7 | 武器图标出现方式（飞行图标 vs 固定面板）与刷新节奏 | 武器补给复刻 | 原版实测（见差异 D4） |

## 4. 复刻策略声明（边界）

1. **代码 / 程序化美术 / 音乐 = 100% 原创**：不复制原版任何代码、图像、音频数据。
2. **本地参考素材仅用于开发对照**：`public/sprites/`（用户合法取得的 NES 剥离图）已写入
   `.gitignore`，**永不入库、永不发布**；缺失时游戏自动回退程序化美术。
3. **像素级还原的诚实边界**：原版素材受版权保护，仓库构建不可能也不允许包含它们；
   因此「像素级还原」仅在本地开发环境成立，对外交付物是「玩法结构忠实 + 原创美术音频」。
   本项目不假装已完成像素级还原——逐项状态见保真度清单。
